# Security policy

## Reporting a vulnerability

Use this repository's **Security → Report a vulnerability** feature for a
private report. Do not use a public issue for vulnerabilities, learner data,
private chat transcripts, provider credentials, or access tokens.

Include the Dari version, Moodle™ version, the affected permission/context,
steps to reproduce on a test site, and the potential impact.
No response-time guarantee is made.

## Release status

The current release is 2.0.0; the repository began with the supplied 1.0.5 package. Marketplace
approval and an independent security audit are not implied by its publication.

## Sensitive information

Use disposable test courses and anonymised evidence. Rotate credentials
through your site's administration if they have been exposed.
